Driver Flow

1. Create the trip here.
2. Press Start when you want the trip active.
3. Tap WhatsApp beside the trip.
4. Driver opens the link and taps START TRIP once.
5. Pause/Resume only changes the trip. The truck record and last GPS location remain available until you manually delete the truck.

No driver email/password or truck selection. GPS and route tracking stay simple for the driver.

Trip Management

Start, pause, resume or remove trips without deleting the truck or its last known GPS location.

Pairing / Security

Each truck gets its own private device token and 6-digit backup pairing code. Use Reset Pairing only when the driver phone is lost or replaced. It invalidates the old driver link.

WhatsApp links contain a truck-specific token. Never post those links publicly.

Fleet Database

Add, edit, archive, reset pairing or manually delete trucks. Trip removal never deletes the truck.
